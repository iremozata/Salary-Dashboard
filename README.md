# Salary-Dashboard


# Overview

This project is an interactive Excel dashboard designed to help job seekers explore salary trends across different data-related roles. It allows users to compare salaries based on job title, location, and other job-related factors, making it easier to understand the data job market and evaluate potential career opportunities.

The project was developed as part of an Excel data analytics learning process, with a focus on turning raw job market data into clear and useful insights through data analysis and visualization.

# Excel Skills Used

The project demonstrates the following Excel skills:

📊 Data Visualization & Charts
🧮 Excel Formulas & Functions
🔽 Data Validation
📋 Data Analysis
🎯 Interactive Dashboard Design

#cDataset

The dataset contains real-world data jobs information, I used the dataset from the course I took. It includes variables related to:

💼 Job titles
💰 Salaries
📍 Job locations
🛠️ Required skills

These variables were used to explore salary differences across roles and locations and to create an interactive dashboard for easier analysis.

# Project Goal

The main goal of this project is to demonstrate how Excel can be used to transform raw job market data into an interactive and easy-to-understand dashboard.

Rather than looking at individual salary records, the dashboard provides a broader view of salary patterns and helps users explore the data from different perspectives.
